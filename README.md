# 🕌 7al, Islamic Prayer Discord Bot

An Islamic Discord bot that helps Muslims remember prayer times through **voice reminders** and **prayer time visuals**.

---

## ✨ Features

### 🔊 Prayer Voice Reminder
- Automatically joins **active voice channels**
- Announces that **5 minutes remain until Adhan**
- Works for all **five daily prayers**

---

### 🖼️ Prayer Time List (Image)
- Generates a **beautiful image**
- Displays daily prayer times clearly
- Can be requested by command
- Ideal for sharing in text channels

---

## ⚙️ How It Works

1. Bot calculates prayer times based on location
2. **5 minutes before Adhan**, bot:
   - Joins voice channels that contain members
   - Plays a voice reminder
3. Users can request the daily prayer schedule as an image

---

## 📌 How To Start the bot ?

Make sure that the .env have the TOKEN & CLIENT_ID then,
```bash
npm install
node cla.js
```
